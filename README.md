# CSI 471/571 Homework 3

`HW3_Report.pdf` contains the solutions and figures. `results/` contains the
full-size outputs and the numerical results for each problem. Coordinates in the
JSON are zero-based image coordinates with x to the right and y down.

## Run the experiments

Use Python 3.12. From this folder, run:

```sh
python -m pip install -r requirements.txt
python solve.py
python capture_objviz.py
python ar_view.py --snapshot
```

Run `python solve.py 3`, for example, to rerun a single problem. The camera
results generated by `solve.py 4` are read by the augmented reality renderer.
The two capture commands use a working desktop OpenGL context. On Linux with
SDL offscreen support, prefix them with
`SDL_VIDEODRIVER=offscreen SDL_AUDIODRIVER=dummy`.

## View the OBJ interactively

```sh
python ObjViz.py inputs/cube1_color.obj
python ar_view.py
```

ObjViz controls are left drag to rotate, right drag to pan, wheel to zoom, and
Escape to quit. The supplied viewer uses the included `ObjLoader.py` adapter.
The AR viewer uses Photo B as the background and uses the OpenGL depth buffer
to render the colored OBJ. Escape closes the AR viewer.

## Reproduce the MeshLab preview

Open `inputs/cube1_meshlab.ply` through **File > Import Mesh** in MeshLab.
Use solid rendering and vertex colors, then rotate and zoom to show multiple
faces. The tested MeshLab release (2020.09) aborted on the supplied OBJ, so
the preview uses a PLY copy of the same geometry and material colors. Each
original quad is split into two triangles, and its vertices carry that face's
diffuse color. ObjViz and the calibrated AR viewer use the original OBJ/MTL.
